# Blog posts

Dated Markdown articles use the schema in [POSTS_FORMAT.md](../POSTS_FORMAT.md). Blog-only rules are in [AGENTS.md](../AGENTS.md). This guide is unpublished because the parent Astro loader scans all Markdown files here.

```text
_posts/YYYY-MM-DD-slug.md
  -> /assets/blogposts/<article>/ images and reference notes
```

The 2026-09-11 mold explainer keeps food-handling exceptions beside the advice and links each claim to a local reference item. Its verification record is in `assets/blogposts/2026-09-11-mold-food-clothes/research.md`.
