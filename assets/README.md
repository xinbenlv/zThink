# Blog assets

This directory stores local media used by articles and the legacy blog theme.

```text
assets/
  blogposts/   # article-specific images and supporting notes
  css/        # legacy theme styles
  fonts/      # local type assets
  images/     # shared and older images
```

New article-specific assets belong in `blogposts/<article>/`; use `/assets/blogposts/...` paths in frontmatter and article markup. See [blogposts/README.md](blogposts/README.md).
